# TaskFlow – Smart To-Do & Notes Manager

## Project Overview

TaskFlow is a React-based productivity application
that helps users manage daily tasks and personal notes
through a single dashboard.

## Features

### To-Do Manager
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
- Set due dates
- Local Storage integration

### Notes Manager
- Create notes
- Edit notes
- Delete notes
- Search notes
- Categorize notes
- Note timestamps
- Local Storage integration

### Dashboard
- Task statistics
- Completed and pending tasks
- Total notes
- Recent activities

## Technologies Used

- React.js
- JavaScript ES6+
- HTML5
- CSS3
- Vite
- React Router
- Local Storage

## Installation

1. Clone the repository.

2. Install dependencies:

   npm install

3. Start the application:

   npm run dev

4. Open the local URL displayed in the terminal.
